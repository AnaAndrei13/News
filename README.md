API to parse an RSS,for returning news list sorted by publication date asc/desc or title alphabetically asc/desc,possibility to search for a keyword,possibility to save the news in a database.

# Technologies
- Java 17
- Spring Boot 3.2.x
- Spring Data JPA
- H2 Database
- Rome (for RSS parsing)

Access API: http://localhost:8082
Access H2 console: http://localhost:8082/h2-console
